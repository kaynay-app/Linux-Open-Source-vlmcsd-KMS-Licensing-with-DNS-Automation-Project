## 🏗️ Architecture & Host Baseline
* The KMS host runs within a highly resource-optimized virtualization layout inside VMware Workstation.
* **Host Platform:** Alpine Linux Native Docker Host (`KMS-SERVER-FQDN`)
* **Container Engine:** Docker Engine Runtime
* **Target Container Image:** `mikolatero/vlmcsd`
* **Network Service Port:** 1688 (KMS Standard Protocol)
